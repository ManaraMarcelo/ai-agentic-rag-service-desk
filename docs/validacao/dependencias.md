# Dependências do projeto

| Dependência | Finalidade |
|---|---|
| langchain | Componentes de integração RAG |
| langchain-core | Mensagens e prompts |
| langchain-community | Carregadores e armazenamento vetorial |
| langchain-google-genai | Gemini e embeddings |
| langchain-text-splitters | Divisão de documentos |
| langgraph | Orquestração dos estados |
| pydantic | Validação estruturada |
| python-dotenv | Variáveis de ambiente |
| pymupdf | Processamento de PDFs |
| faiss-cpu | Busca vetorial |
| ipykernel | Execução em notebooks |

## Verificação
